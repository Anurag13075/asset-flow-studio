
# Vaultgrid

**Local-first asset manager for design studios.**

Every design, video, 3D, and font file you own — indexed right where it lives on your drive. No uploads, no cloud lag, no monthly fees.

LIVE: [screenfast.site ](https://www.screenfast.site/)

---

## Why Vaultgrid exists

I got tired of digging through nested folders hunting for files I knew I had somewhere. Cloud asset managers charge $15–50/month per seat and want your original files uploaded to their servers just to make them searchable.

That felt backwards. Your files already live on your machine — they shouldn't have to leave it to be findable.

Vaultgrid indexes everything locally instead: sub-10ms search, zero uploads, one-time $2 payment. Your files, your machine, actually findable.

---

## Features

- ⚡ **Sub-10ms search** — local inverted index over filenames, tags, and embedded metadata
- 🏷️ **Auto-tag on import** — filenames, folder ancestry, and file type become structured tags automatically
- 🔍 **Duplicate radar** — flags identical/related files so you can reclaim storage without touching originals
- 🎨 **Color-family filter** — bins assets by palette at index time for instant visual filtering
- 📊 **Vault insights** — growth over time, storage by kind, and your working tag vocabulary
- ⌨️ **Keyboard-native** — ⌘K command palette, no mouse required
- 🔒 **100% local** — nothing is uploaded; originals never leave your device
